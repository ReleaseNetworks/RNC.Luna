# RNC.Luna

## Overview

RNC.Luna is one of our teams research project that utilizes neural models to classify emails, helping organizations improve their cybersecurity.

The model is trained on our own synthetic datasets, generated with open-weight models such as Mistral-Nemo. The datasets include more than 250,000 synthetic emails spanning business and private contexts. Part of the data is already published on Huggingface, and we plan to release the remaining data to maximize transparency.

## Real-world use cases and implementations

We plan to release an open-exchange plugin and a Microsoft Exchange Online connector, so organizations can integrate RNC.Luna into their existing mail systems. Further specifications will follow once the complete system is in place. We also plan to publish test results and implementation guides.
